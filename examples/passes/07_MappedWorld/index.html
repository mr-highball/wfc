04 / INSPECT & EDIT

A site is a region, not an index

Selecting a site only inspects it. Apply demand changes its domain and invalidates the current output; it does not generate a house.

Generate a baseline to inspect actual provider cells.
Paint a cell domain or caller lock

Domains limit what may be generated. Allow both relaxes a study cell's zoning; restore returns it to the preset (free in the sandbox). Locks are explicit caller-owned values. A terrain edit needs the all-pass scope; a foliage edit needs foliage + housing.

TRY IT

The tree that the corner misses

  1. Use the interior study, seed 3, and whole-footprint sampling. Generate a baseline: WFC produces the tree at (7,7).
  2. Select site 0,0 and require a house. Its 8 × 8 footprint includes the tree, although its lower corner at (4,4) is clear.
  3. Try housing-only repair. It must respect the unchanged foliage, so it fails.
  4. Authorize foliage + housing repair. Negotiation can now choose another foliage assignment. The terrain stays unchanged.
  5. Start a separate point-sampling study to see the counterexample: the selected rules may pass while physical clearance fails.

The coordinator excludes complete provider assignments; it does not infer the smallest conflicting region. Freer sandbox worlds can need many attempts or exhaust the chosen budget. No seed search, hidden retry, or automatic clearing is performed.
