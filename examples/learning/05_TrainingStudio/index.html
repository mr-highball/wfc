02 / RUN

Bounded solve

Whole-output quotas

Hard quantities, separate from learned frequencies. A cell counts once if its token is in the selected set. Every saved quota must hold.

Select one or more tokens (Ctrl / Command or Shift on desktop). Tokens are displayed with canonical escaping. Bounds are absolute integers, not percentages; resizing does not change them.

Train the current source to choose public tokens.

Apply rebuilds the recipe and saves quotas in the editable .wfclearn source. Download source to keep them. Standalone model export cannot retain quotas; use the source or recipe.

Rooted connectivity networks

Explicit public-token ports, independent of learned adjacency. Every saved network must hold. Nonparticipants are not traversable.

The demonstration replaces the source with all local road/grass pairs, then authors a 4×3 route from (0,0,0) to (3,2,0) with exactly six roads. It is separate from the six original presets.

Coordinates are absolute and nonnegative. Saving sorts terminals by Z, Y, X; duplicates and the root as a terminal are rejected. Rank-1 sources require Y=Z=0; rank-2 requires Z=0. Output bounds are checked when configuring the run.

Ports are never inferred. N is +Y, E is +X, Up is +Z; edges need reciprocal ports and allowed learned adjacency. “Required by value” requires every occurrence of that participating token to reach the root. Unchecked participants' ports and required flags are not saved. Existing authored profile order is retained; new participants append in public vocabulary order.
