07 / CONTINUOUS STREAM

Preparing duration preflight…

No stream save is active.

This generates a fresh composition using the current seed, composition profile, and stream settings. It does not export the finite score above or transfer that editor's locks and repair scope. Stream search/trace controls apply to acoustic segments; the developed phrase planner uses its fixed 256/64 allowances described above.

Requested time is rounded up only to the next eighth-note cell at 120 BPM, and the actual duration is shown before a destination is chosen. There is no minute policy ceiling; exact numeric, WAVE/RF64, MIDI, storage, and search constraints still apply. Five-cell working segments deliberately cross held bass and chord boundaries. WAVE generation, synthesis, and saving retain one bounded segment and one PCM block rather than a whole-song audio buffer.

MIDI is an explicit two-pass transaction: Plan MIDI first counts the complete deterministic format-0 track without opening a picker or retaining frames. A later user click on Save planned MIDI chooses a destination, regenerates the same frame stream, writes one block at a time, and closes only after its tick, byte, event, and generation fingerprints match the plan.

Browser file contract: Save As is controlled by the browser and may replace a file that you select. This differs from the native renderer, which requires a new path and atomically refuses replacement. Cancellation or failure before browser close never claims a completed stream.
